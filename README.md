# Zentrevo — Luxury Travel & Curated Expeditions Frontend

A modern luxury travel and curated expedition frontend built with **React**, **Vite**, and **Tailwind CSS**, featuring an interactive dual-theme engine (*Emerald Luxe* & *Editorial Mono*).

## ✨ Features & Templates Incorporated

- **Dual-Theme Engine (Live Toggle)**:
  - **Emerald Luxe (Template 2 - Breezio Style)**: Deep forest emerald aesthetic with mint accents and organic wave transitions.
  - **Editorial Mono (Template 1 & 3 - Travelio & Travel Style)**: Minimalist editorial serif typography, monochrome palette, and warm amber tags.
- **Floating Viewport Canvas**: Rounded inner viewport container with scenic landscape atmosphere.
- **Chamfered Feature Card**: Signature diagonal cut-corner destination card with interactive next/prev slider and `(FIRST) (PRESENT) 01` pagination.
- **Floating Neumorphic Booking Bar**: Interactive quick search with live dropdowns for Destinations, Travel Dates, and Guests.
- **Metrics & Social Proof Ribbon**: High-impact counters (200+ Destinations, 25 Years of Experience, 20k+ Happy Travelers, 98% Satisfaction) and luxury partner logos.
- **Curated Destinations Grid**: Category filters (Luxury Escapes, Cultural, Trending, Alpine Nature) with country badge tags and pricing.
- **Core Beliefs & "Why Choose Us"**: 3-pillar ethos cards and the iconic floating "25 Years Of Excellence" experience showcase.
- **Cinematic Video Chronicle**: 4K landscape reel preview with interactive video player modal.
- **Interactive Itinerary Detail Modal**: Full day-by-day highlights, pricing inclusions, and direct booking trigger.
- **"Voyages of Wonder" Inquiry Form**: Complete bespoke itinerary request form with instant feedback.

## 🚀 Quick Start (Run Locally)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
